> 本記事は、個人開発 + 各種 AI ツール協働で制作している HD-2D 探索アドベンチャー **Anemora** の進捗発信です。コンセプトと制作体制は [Anemora 紹介記事](https://zenn.dev/marvelousu/articles/anemora-hd2d-time-frame) を参照してください。今回は、実際に遊べる**体験ビルド**を初めて公開したので、その報告です。

## 何を公開したか

2026-05-18 に、Anemora の**体験ビルド**を GitHub Releases で公開しました(リポジトリ上の呼称は Fast VS。Chapter 1 の一区切りです)。

- 入手先: https://github.com/marvelousu/anemora/releases/latest
- 配布物: Windows ビルド一式の zip(約 38 MB)、タグ `vs-public-2026-05-18`

ニロ(主人公)の家の中から始まり、家の外、中央広場、図書館へと進み、図書館で「レト」と本のイベントを経て **時の窓** が解放され、そのままクリアまで到達できます。

ゲーム制作はこの作品が初めてで、設計から実装・アート・音まで AI を相棒に回しています。ささやかな区切りではありますが、頭の中にあった『時の窓』を、実際に動かせる形にできました。自分にとって素直に嬉しい一歩です。

## どう遊ぶか

1. [最新リリース](https://github.com/marvelousu/anemora/releases/latest) から zip をダウンロードして展開します。
2. フォルダ内の `Anemora_FastVS_HouseSlice.exe` を実行します。`.exe` だけを別の場所へ移さず、同じ階層の `Anemora_FastVS_HouseSlice_Data/` などと一緒に置いたまま起動してください。
3. 署名なしビルドのため、Windows SmartScreen の警告が出る場合があります。「詳細情報」→「実行」で起動できます。

操作は次のとおりです。

| 操作 | 入力 |
|---|---|
| 移動 | `WASD` / 矢印キー |
| インタラクト / テキスト送り | `E` / `Space` / `Enter` |
| マップ間の移動 | 光る床パッドの上を歩く |
| 時の窓を生成 | レトのイベントで解放後、画面を左ドラッグ |
| 時の窓を閉じる | 現在側にいるとき右クリック または `Esc` |

想定ルートは「ニロの家(室内) → 家の外 → 中央広場 → 図書館 → レト / 本 / 時の窓イベント → VS クリア」です。対応プラットフォームは現状 Windows のみです。

## このスライスで触れる中核「時の窓」

Anemora の中核は、空中にフレーム(時の窓)を描いて過去や別の時点を覗き、そこで取った小さな行動が現在側の風景や進行に反映される、という循環です。コンセプトの全体像は紹介記事に書いたとおりですが、今回の Fast VS では、その循環の入口を実際に手で動かせます。

このスライスで確かめられるのは、時の窓を出して別の時間へ踏み込み、また戻ってくる、という操作そのものの手触りです。ゲーム開始時は時の窓の入力はロックされていて、図書館でレトのイベントを踏むと解放されます。以降は画面を左ドラッグして時の窓を出し、境界をまたいで向こう側へ入り、戻ってくる、という一連を操作できます。閉じられるのはニロが現在側にいるときだけ(右クリック または `Esc`)で、過去側にいる間は閉じられません。これは過去に取り残されないための意図的な仕様です。戦闘はありません。一方で「過去で取った行動が現在側に反映される」というコアループの帰結部分は、物語構成の都合でこのスライスより後の段階に置いており、ここではまだ体験できません。

## どう作ったか

Anemora は個人開発で、現時点では設計対話と取りまとめを Claude、実装と並列加速を Codex、アセット生成を PixelLab / Aseprite / Meshy / Blender / Suno / ElevenLabs などに分担させるパイプラインで進めています。この Claude と Codex の役割分担は固定的なものではなく、いくつかの運用方法を試した末に今の形に落ち着いたもので、今後も試行を重ねる中で変えていく可能性があります。技術スタックは Unity `6000.3.14f1` + URP `17.3.0` です。

この体制で進める中で、いちばん手こずったのはグラフィックでした。AI に生成や修正をさせてはビルドを起こし、見栄えを確認しては差し戻す、というやり取りを何度繰り返しても想定の水準に届かず、修正を重ねるほど良くなるという感触が持てません。最終的に「既存のグラフィックは作り直す」と判断しました。AI に手を動かしてもらいつつ、どこで見切りをつけて方針ごと変えるかは人間側で決める、という分担がはっきり出た場面でした。

旧版は完全に不採用とし、新しいビジュアル方針のもとで本編のシーンを作り直しました。それがこの Fast VS(`Anemora_FastVS_HouseSlice`)で、旧マップや旧グラフィックは引き継いでいません。範囲は家・外・中央広場・図書館に絞り、レトのイベントから時の窓を解放してひと回りする 1 本道までを通しています。

![開発初期のころの画面](/images/anemora-vs/early-library.png =550x)  
*開発初期のころの画面。現在の見た目は全面的に一新*

現在の状態を公開ベースラインとして `main` に固定し、タグ `vs-public-2026-05-18` を付けて公開しました。公開タグは安定版として据え置き、以降の開発はこのシーンを土台に作業ブランチで続けています。日々の判断や検証は devlog として `docs/devlog/` に残してあります。

## 正直なスコープと制限

現時点の制限を明示しておきます。

- **Windows のみ**。配布ビルドは未署名で、SmartScreen の警告が出る可能性があります。
- **短いスライス**です。Chapter 1 のうち、家・外・中央広場・図書館と、レトのイベントから時の窓をひと回りする 1 本道に絞っています。フルゲームでも Chapter 1 全体でもありません。
- **コアループの帰結(過去の行動が現在に反映される結末)はこのスライスには未収録**です。時の窓の操作は体験できますが、その反映は物語構成の都合で後の段階に置いています。
- **開発途中の公開ベースライン**です。このシーンを土台に開発を継続中で(グラフィック改善を含む)、細部のポリッシュや調整は未了の項目が残っています。
- 主人公名「ニロ」や地名などは **仮名称**で、今後のレビューで変わる可能性があります。
- コードライセンスは既定で All Rights Reserved です(企画書・仕様書・devlog などのドキュメントは引き続き GitHub で公開しています)。
- 正式な公開経路は Steam Early Access を主軸に想定していますが、時期・条件は未定です。今回のものはあくまで開発途中の体験ビルドです。
